# Changelog

## v0.1 — Récolte + Inventaire + Temps

### Fonctionnalités
- Récolte de bois et de baies via la touche **E**
- Détection basée sur la vraie zone `Area2D` (`GatherShape`) de chaque ressource
- Label d'interaction affiché uniquement quand le joueur est dans la zone
- Système d'inventaire de base (bois, baies, nourriture, pierre)
- Système de temps : cycle jour/nuit, heure affichée dans le HUD
- HUD avec affichage des ressources en temps réel
- Génération du monde par chunks
- Spawn aléatoire des ressources (arbres, buissons)
